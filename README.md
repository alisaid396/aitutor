# 📖 Project Overview

**AI Tutor Assistant** is an AI-powered educational assistant that helps students understand and interact with their learning materials through a **Retrieval-Augmented Generation (RAG)** system.

The user can upload educational PDF files, and the system processes the content into searchable chunks. Students can then ask questions about the uploaded material, request explanations, generate quizzes, and evaluate their own answers.

The system is designed to provide answers based primarily on the student's uploaded educational material rather than relying only on the model's general knowledge.

The project follows a **Frontend–Backend architecture**:

* **Streamlit** is used for the interactive frontend.
* **FastAPI** provides the backend API.
* **Qwen2.5-3B-Instruct** is used as the Large Language Model.
* **Multilingual E5** is used for semantic embeddings.
